### Generate Access Key ID and Secret Access Key

1. In the **IAM users** interface.

    - Select **IAM users**
    - Select **Security credentials** tab

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0001.png)

2. Select **Create access key**.

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0002.png)

3. Select **Command Line interface(CLI)**.

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0003.png)

4. In the **Confirmation** interface.

    - Select **I understand the above recommendation and want to proceed to create an access key.**
    - Click **Next** and **Create access key**

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0004.png)

5. In the **Retrive access keys** interface.

    - Review **Access key** and **Secret access key**
    - Click **Download .csv file** to save the file

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0005.png)

6. Select **Downloads** and click **Save** on this PC.

    - Click **Done**
    - Review **Access key 1**

![Generate access ID and secret access](/static/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0006.png)
