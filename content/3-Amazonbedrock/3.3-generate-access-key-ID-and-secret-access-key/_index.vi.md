### Tạo Access Key ID và Secret Access Key

1. Trong giao diện **IAM users**.

    - Chọn **IAM users**
    - Chọn tab **Security credentials**

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0001.png)

2. Chọn **Create access key**.

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0002.png)

3. Chọn **Command Line Interface (CLI)**.

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0003.png)

4. Trong giao diện **Confirmation**.

    - Chọn **I understand the above recommendation and want to proceed to create an access key.**
    - Nhấn **Next** và **Create access key**

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0004.png)

5. Trong giao diện **Retrieve access keys**.

    - Kiểm tra **Access key** và **Secret access key**
    - Nhấn **Download .csv file** để lưu file

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0005.png)

6. Chọn thư mục **Downloads** và nhấn **Save** trên máy tính.

    - Nhấn **Done**
    - Kiểm tra lại **Access key 1**

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0006.png)

![Generate access ID and secret access](/images/3-Amazonbedrock/3.3-generate-access-key-ID-and-secret-access-key/0007.png)
