### Đăng nhập IAM User (IAM User Sign In)

1. Truy cập vào [AWS Sign in](https://signin.aws.amazon.com/signup?request_type=register).

    - Chọn **Sign in to an existing AWS account**

![IAM User Sign in](/images/3-Amazonbedrock/3.4-iam-user-sign-in/0001.png)

2. Trong giao diện **IAM user sign in**.

    - **Account ID**: nhập ``your-account-ID``, ví dụ: **Account ID**: 123456789012
    - **IAM username**: nhập ``bedrock-ai-chatbot-user``
    - **Password**: nhập ``Password123``

![IAM User Sign in](/images/3-Amazonbedrock/3.4-iam-user-sign-in/0002.png)

3. Sau khi đăng nhập thành công vào AWS Management Console.

![IAM User Sign in](/images/3-Amazonbedrock/3.4-iam-user-sign-in/0003.png)
